# Systems Programming

Course materials and assignments for Systems Programming.

## Overview

Shell, text-processing, and C programming coursework focused on Linux systems work.

## Folder Map

- Assignment-0-Linux-Familiarity: Bash script and output with assignment PDF.
- Assignment-1-Shell-Scripting: Shell scripts for CRUD operations with assignment PDF.
- Assignment-2-Sed: Sed script and Bash driver with assignment PDF.
- Assignment-3-Awk: Awk and shell scripts with input data and assignment PDF.
- Assignment-4-Process-Control: C program with Makefile and assignment PDF.

## Run / Build

- Use the shell scripts or Makefiles in each assignment folder to run the work.
- Follow the assignment PDF for any required sample inputs or command-line arguments.
