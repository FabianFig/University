# Fundamentals of Object Oriented Programming

Course materials and assignments for Fundamentals of Object Oriented Programming.

## Overview

Java coursework focused on object-oriented design, inheritance, and data-driven class modeling.

## Folder Map

- Project-0: Intro Java program with assignment PDF.
- Project-1: Product and media inventory classes with dataset CSV and PDF.
- Project-2: Patient and medical staff management with CSV data and PDF.

## Run / Build

- Open each project folder in your Java IDE or compile from the command line as needed.
- Use the provided CSV inputs and assignment instructions for each project.
