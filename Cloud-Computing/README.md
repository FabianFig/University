# Cloud Computing

Course materials and assignments for Cloud Computing.

## Overview

Cloud computing coursework covering Docker, Docker Compose, and AWS S3 with Python/Flask.

## Folder Map

- Assignment-2: Dockerized Flask app for Celsius/Fahrenheit conversion.
- Assignment-3: Docker Compose example with a Flask web service and Redis.
- Assignment-4: Flask app for uploading and managing images in AWS S3.
- Project: Group project - Flask + MongoDB smart task tracker.

## Run / Build

- Follow the README inside each assignment folder for setup and run instructions.
- Docker and/or AWS credentials are required depending on the assignment.
