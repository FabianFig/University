# Web Technologies

Course materials and assignments for Web Technologies.

## Overview

HTML, CSS, JavaScript, PHP, and MySQL coursework for web development.

## Folder Map

- hw2: Basic HTML homepage with images.
- hw3: HTML homepage with table layout and inline styling.
- hw4: HTML homepage with an external CSS stylesheet.
- hw5: Multi-page site styled with Bootstrap and Font Awesome.
- hw6: Multi-page site with JavaScript dynamic content.
- hw7: JavaScript form validation and event handling.
- hw8: JavaScript shopping cart with form validation.
- hw9: Shopping cart site introducing PHP (`index.php`).
- hw10: HTML/PHP site with contact form and results handling.
- hw11: PHP contact form and results processing.
- hw12: PHP server-side form validation helpers.
- hw13: Full PHP multi-page site with shared navigation.
- hw15: PHP multi-page site with contact form and navigation.
- hw16: PHP site with MySQL-backed contact storage.
- hw17: PHP site querying a MySQL contacts database.
- hw18: PHP site with registration, login, and sessions.

## Shared Assets

- Shared images, stylesheets, and scripts used across the homework folders live in [assets](assets) (`css/`, `images/`, `js/`).
- Each homework folder keeps empty `assets/` subdirectories (`css/`, `images/`, `js/`) so the per-assignment structure is preserved; reference the shared folder for the actual files.

## Run / Build

- Open the HTML pages directly in a browser.
- PHP assignments require a PHP server; MySQL-based assignments require a database connection.
