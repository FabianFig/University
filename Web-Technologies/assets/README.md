# Shared Assets

Shared frontend assets used across the Web Technologies homework folders.

## Contents

- `images/`: Common images (`20260408_0032.jpg`, `20260408_0033_01.jpg`) referenced by the homework assignments.
- `css/`: Shared stylesheets (`bootstrap.min.css`, `styles.css`).
- `js/`: Shared scripts (`add-content.js`, `dom-event-handler.js`, `event-listener.js`, `html-event-attributes.js`, `jquery-3.5.1.js`, `shopping-cart.js`, `validation.js`).

Each homework folder keeps empty `assets/css/`, `assets/images/`, and `assets/js/` directories so the per-assignment structure stays visible; the actual files live here.
