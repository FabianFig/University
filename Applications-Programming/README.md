# Applications Programming

Course materials and assignments for Applications Programming.

## Overview

Java coursework focused on object-oriented design, JavaFX, and data-backed desktop applications.

## Folder Map

- Lab1: Java class hierarchy for ships and rescue services.
- Lab2: CSV-backed aid ship manager with UML diagram and Java classes.
- Lab3: JavaFX app with FXML layout, images, and aid ship data.
- Lab4: JavaFX app with login/main screens, CSV data, and UML diagram.
- Final-App-Chrono: JavaFX app with controllers/models, FXML layouts, CSS themes, images, and data files.

## Run / Build

- Open the individual lab or project folder in your IDE and follow the assignment instructions or included README files.
- JavaFX projects may require the JavaFX SDK and a configured module path.
