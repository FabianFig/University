# Applied Linear Algebra

Course materials and assignments for Applied Linear Algebra.

## Overview

Python coursework centered on numerical methods, linear algebra applications, and small analytical projects.

## Folder Map

- Project-1: Python scripts and reports for time series and trapezoid work.
- Project-2: PageRank Python implementation with report.
- Final-Project: Neural network Python code with diagrams and report PDFs.

## Run / Build

- Use the scripts in each project folder directly with Python.
- Install any notebook or plotting dependencies before running the assignments.
