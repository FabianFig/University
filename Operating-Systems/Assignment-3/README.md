# Assignment 3
Virtual memory address translation simulator with page table management and LRU page replacement, in C.

## Highlights

- `part1.c`: address translation using a fixed page-to-frame mapping.
- `part2.c`: page table and physical frame manager (`pagetable.c`, `phypages.c`) with LRU replacement.
- `part3.c`: adaptive version with configurable page size and memory sizes (extra credit).
- Build with the included Makefile; report in `REPORT.txt` and spec in `assignment3.md`.
