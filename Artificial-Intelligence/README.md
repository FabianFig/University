# Artificial Intelligence

Course materials and assignments for Artificial Intelligence.

## Overview

AI coursework in Jupyter notebooks covering search agents, game playing, machine learning, and deep learning.

## Folder Map

- Homework-1: Uninformed and informed search agents for a Texas cities graph.
- Homework-2: Chess game with board setup, rules, Random AI, and MinMax AI.
- Homework-3: Stochastic Gradient Descent and ID3 decision tree implementations.
- Homework-4: Deep learning with CNNs (CIFAR-100) and RNNs (Reuters).
- Project: Course project proposal and final presentation.
- Quizzes: In-class quiz PDFs.

## Run / Build

- Open the notebooks in a Python/Jupyter environment (Google Colab recommended).
- Install the required ML libraries before execution.
