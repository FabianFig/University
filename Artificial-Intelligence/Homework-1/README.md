# Homework 1
Jupyter notebook implementing uninformed (BFS) and informed (heuristic) search agents for a Texas cities graph built from `cities.csv` and `distances.csv`.

## Highlights

- Reads `cities.csv` and `distances.csv` to build a 2D graph overlaid on `texas-map-2.png`.
- Uninformed search agent (BFS) models virus spread from Three Rivers.
- Informed search agent distributes vaccine from San Antonio to College Station.
